# Ordered list numbering

1. first
2. second
7. third

A top-level paragraph ends the list.

3. this list starts at three
9. and keeps that start

Nested lists count on their own:

1. outer
   1. inner
   4. inner two
2. outer two

A bullet list takes over the level:

1. ordered
- bullet

Switching the delimiter starts a new list:

1. dot
1) paren

Markers inside a fence are untouched:

```
1. one
9. nine
```
